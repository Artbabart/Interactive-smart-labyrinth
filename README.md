# Smart Labirintus

Interaktív, projektorral támogatott oktatási rendszer
óvodáskorú gyermekek algoritmikus gondolkodásának fejlesztésére.

## Technológiák

- Angular
- Phaser.js
- Laravel
- MySQL
- ESP32
- FSR nyomásérzékelők

## Projekt felépítése

- `frontend/` – Angular és Phaser alkalmazás
- `backend/` – Laravel REST API
- `firmware/` – ESP32 program
- `docs/` – dokumentáció és tervek

## Állapot

Fejlesztés alatt.
